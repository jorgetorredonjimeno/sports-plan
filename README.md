# Sports Plan

App personal de Jorge: plan de carrera por meses, rutina de gym, zapatillas, menú semanal y lista de la compra.

Se abre en https://jorgetorredonjimeno.github.io/sports-plan/ y se puede instalar en el móvil (Añadir a pantalla de inicio). Los datos se guardan solo en el aparato; la pestaña **Copia** permite guardarlos en un archivo y recuperarlos.
